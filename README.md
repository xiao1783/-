# 构页有方

“构页有方”是《可视化导论》课程的桌面端中英双语交互式教学网站，通过同一个“课程主页重构”案例讲解如何分析、选择和验证网页布局。

网站不是单纯介绍 CSS 属性，而是从内容关系、空间约束、视觉层级和阅读路径出发，帮助学习者建立可重复使用的页面布局判断方法。

## 项目特点

- **案例驱动**：七个章节围绕“重构课程主页”这一案例逐步展开。
- **理论与实践结合**：每章均包含讲解、关键代码和动态演示。
- **交互式学习**：可通过按钮、滑块和节点选择观察布局变化。
- **中英双语**：页面右上角可切换中文与英文，两种语言内容保持一致。
- **课程阅读器布局**：采用左侧章节目录、中间学习内容、右侧页内目录的桌面端三栏结构。
- **统一视觉系统**：以深蓝灰为正文色、紫色为主强调色、橙色为案例提示色。

## 课程章节

| 章节 | 主题 | 核心内容 | 动态演示 |
| --- | --- | --- | --- |
| 第 1 章 | 布局的本质 | 内容关系、DOM 层级、空间约束与阅读顺序 | DOM 树与页面区域联动 |
| 第 2 章 | 视觉层级与色彩 | 视觉重量、颜色角色、对比度与可读性 | 色彩层级切换 |
| 第 3 章 | 字体、间距与对齐 | 字号层级、行长、留白、基线与邻近原则 | 字号比例与间距调节 |
| 第 4 章 | 盒模型与正常文档流 | content、padding、border、margin 与元素占位 | 盒模型尺寸计算 |
| 第 5 章 | Flexbox 与 Grid | 一维和二维布局、剩余空间与布局模型选择 | Flexbox/Grid 实时切换 |
| 第 6 章 | 定位、层叠与组件 | 定位参照、文档流、层叠上下文与 z-index | 图层和定位方式调节 |
| 第 7 章 | 综合案例：重构课程主页 | 从结构诊断到布局选择的完整分析过程 | 页面布局问题检查与修复建议 |

## 教学结构

每个章节固定包含三个部分：

1. **讲解**：提出案例问题，解释相关布局理论和设计原则。
2. **关键代码**：展示实现当前空间关系所需的核心 HTML/CSS。
3. **动态演示**：通过可操作的可视化模型观察浏览器如何重新计算布局。

首页采用“观察 → 建模 → 验证”的学习过程：

- **观察**：识别内容角色、阅读顺序和当前页面问题。
- **建模**：把视觉问题转换为包含、对齐、流动和层叠关系。
- **验证**：使用真实 CSS 与交互演示验证布局判断。

## 本地运行

项目不需要安装依赖，也不需要构建工具。

### 推荐方式

在项目目录打开 PowerShell，运行：

```powershell
python -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000/
```

按 `Ctrl + C` 可以停止本地服务器。

### 直接打开

也可以直接双击 `index.html`。如果浏览器对本地文件资源有限制，建议使用上面的本地服务器方式。

> D3.js 当前通过 CDN 加载。首次打开动态演示时需要保持网络连接。

## 技术实现

- HTML5
- CSS3：Grid、Flexbox、定位、层叠与响应式断点
- 原生 JavaScript
- D3.js 7：DOM 层级、盒模型和色彩关系等可视化演示
- LocalStorage：保存中英文语言选择

## 页面适配

本项目按照作业要求专注于桌面端：

- 1440–1920px 屏幕下使用三栏课程阅读器布局。
- 整体内容宽度限制在约 1280–1440px，并在页面中居中。
- 空间不足时自动隐藏右侧辅助目录，保留课程目录和主要学习内容。
- 不针对手机端进行专门适配。

## 使用说明

- 点击左侧课程目录进入对应章节。
- 点击右上角语言按钮切换中文或英文。
- 在章节演示区域调整参数，观察页面结构和布局结果变化。
- 首页章节路径与案例示意区域可以联动，用于预览每章关注的布局问题。
