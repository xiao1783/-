# 构页有方 · 可视化导论

“构页有方”是《可视化导论》的桌面端中英双语交互式课程网站。课程不把 CSS 当作孤立属性来讲，而是从内容关系、空间约束、视觉层级、阅读路径和 DOM 结构出发，帮助学习者理解一个网页为什么这样组织，以及浏览器如何把结构计算成最终页面。

项目的贯穿案例是一张课程学习页面。学习者会先观察页面问题，再建立关系模型，随后理解页面骨架、盒模型、排版节奏、布局模型和浮层行为，最后回到综合案例中完成判断与验证。

## 核心定位

项目由两种互补的学习体验组成：

1. **课程阅读器**：提供章节、理论、代码、案例背景和小节练习。
2. **可交互布局实验**：把布局参数、DOM、CSS 和浏览器计算结果变成可以直接观察和操作的对象。

Global Workspace 的定位是一个极简的 **Web Layout Playground**：默认首先呈现一张真实课程网页；用户点击元素后，才出现轻量浮动属性面板和编辑器能力。它不是 Figma 式的自由画布，也不是由矩形拼成的教学示意图，页面本身就是实验对象。

## Global Workspace：极简真实网页编辑器

### 页面结构

Global Workspace 当前只保留三层：

1. **极简顶部工具栏**：返回课程、品牌标识、选择、拖动、网格、边界、DOM、CSS、对比、重置。
2. **真实网页 Canvas**：占据绝大部分实验空间，内部渲染真实 HTML / CSS 课程学习页面。
3. **浮动属性面板**：只有用户选中元素后才出现，覆盖在 Canvas 上方，不占用常驻底部区域。

顶部工具栏与 Canvas 共用统一版心，采用浅灰环境、圆角容器、轻边框和柔和阴影。Canvas 内允许网页自然纵向滚动，不为了把整张网页塞进一屏而强制压缩内容。

### 真实网页内容

Canvas 中的页面由真实 DOM 组成，包含：

- 课程 Header：品牌、导航和学习进度。
- 章节导航 Aside：第一章标题、5 个学习步骤和完成状态。
- Hero：课程引导、标题、简介和开始学习按钮。
- Principle：浅紫色原则提示区。
- Relation Model：包含、流动、对齐和优先级等内容关系。
- Learning Content：观察问题、建立模型、验证布局等学习内容。
- Intro：正文式内容段落和内容关系说明。
- Demo Area：观察宽度、间距和侧栏比例如何影响空间分配。
- Learning Notes：阅读宽度、间距和层级提示。
- Next Section：下一节入口。
- Footer：构页有方和 Layout with intent。

页面不使用截图、背景图片、Canvas 2D 绘图或 iframe 模拟网页。尺寸、间距、顺序和文本变化都通过真实 DOM、CSS 和浏览器布局计算产生。

### 元素选择

Canvas 中的真实网页元素都会被注册为可编辑节点，可以点击 Header、Aside、Main、Hero、Section、Card、Demo、Footer 以及内部真实标题、段落和内容区域。

默认状态下：

- 不显示选中框。
- 不显示 HEADER / MAIN / ASIDE 等编辑器标签。
- 不显示常驻属性面板。
- 网页看起来像一个正常可发布的网站。

点击元素后：

- 真实元素出现品牌紫色轻量选中轮廓。
- Overlay 显示元素名称，例如 `h2`、`section.global-course-intro`。
- 浮动属性面板根据选中元素位置自动避让。
- 面板显示宽度、最小高度、内边距、下方间距等当前值。
- CSS 视图显示当前节点对应的真实样式。
- DOM 视图显示从页面容器到当前节点的层级路径。

### 宽度和尺寸编辑

选中元素后，可以通过浮层数值输入或 Overlay 边缘直接调整：

- `width`：改变元素宽度并触发真实页面 reflow。
- `min-height`：改变元素最小高度。
- `padding`：改变元素内边距。
- `margin-bottom`：改变元素与下方内容的距离。
- Grid 子项的 `grid-column`：按照网格跨度调整卡片，而不是生成随意的绝对坐标。

侧栏宽度变化会同步写入父级 Grid 的 `grid-template-columns`，例如：

```css
.course-body {
  grid-template-columns: 240px minmax(0, 1fr);
}
```

调整尺寸后，网页内容会按照正常文档流、Grid 或 Flex 规则重新排版。文字换行、区块高度、相邻内容位置和整体页面高度都会随之变化。

### 间距和 Grid 语义

当选中 Grid / Flex 容器时，浮动面板会显示 `gap`。间距编辑写入真实 CSS `gap`，不会通过绝对定位把元素移动到任意坐标。

Card 的宽度调整遵循网格语义：

- 卡片可以在单列和跨列之间切换。
- 使用 `grid-column: span 2` 这样的语义化属性。
- 不生成 `width: 617.381px` 之类破坏 Grid 教学意义的自由尺寸。

### 拖动与排序

拖动模式用于同级元素重排：

- 元素只能在当前合法父容器中移动。
- 采用真实 DOM 顺序，不使用任意 `absolute` 坐标。
- 拖动过程中显示插入位置提示。
- 松开后通过 `insertBefore` 更新真实 DOM 顺序。
- 顺序会同步记录到 Workspace 状态。
- 一次拖动对应一次保存，避免一次鼠标移动产生大量历史记录。

选择模式主要用于选择元素和使用边缘控制点调整尺寸；拖动模式用于明确执行同级排序，减少误把点击当成自由移动的情况。

### DOM 和 CSS 双向观察

- **DOM**：展示页面容器、父节点、同级节点和当前节点的真实层级路径。
- **CSS**：展示当前元素已有的真实 inline CSS；没有 inline 声明时显示实际尺寸注释。
- 点击 Canvas 元素会更新当前 DOM / CSS 面板。
- 切换 DOM 或 CSS 时保留当前选中状态。
- 元素发生尺寸变化后，浮层数值和 CSS 内容同步刷新。

### Overlay 开关

编辑器辅助信息不会写入网页内容层：

- **网格**：开启时显示淡色网格辅助线。
- **边界**：开启时显示真实可编辑节点的轻量虚线边界。
- **选中轮廓**：只在用户选中元素后出现。
- **尺寸控制点**：只在用户选中元素后出现，并根据元素能力提供宽度、高度或排序控制。

Overlay 的坐标来自真实元素的 `getBoundingClientRect()`，并相对于 Canvas 容器换算。窗口 resize、Canvas scroll、页面尺寸变化和 ResizeObserver 会触发重新计算，保证网页滚动后辅助层仍然跟随元素。

### 对比和重置

- **对比**：切换 Original / Current 状态。Original 使用本章默认布局，Current 保留用户当前编辑结果。
- **重置**：点击后弹出确认，恢复本章 Workspace 的初始页面宽度、侧栏比例、间距和卡片跨度。
- 重置只作用于本章实验状态，不修改其他章节课程进度和测验状态。

## 小节动态实验

除 Global Workspace 外，每个章节的小节 Demo 都有独立实验状态和可视化模型。

### 第 1 章：DOM 结构

- 展示 `main.course-page`、`header.course-header`、`div.course-body`、`aside.chapter-nav` 和 `section.course-content` 的结构关系。
- 点击结构节点时，页面骨架对应区域同步高亮。
- 展示内容容器、章节导航、课程内容和演示区域的职责。

### 第 2 章：色彩层级

- 切换平衡、低饱和和高强调色彩方案。
- 观察背景、结构、强调和交互角色的视觉重量。
- 显示对比度结果和可读性提示。

### 第 3 章：字体、间距与对齐

- 调整字号比例和区块间距。
- 观察行长、基线、文字层级和阅读节奏变化。

### 第 4 章：盒模型

- 调整 padding、border 和 margin。
- 切换 `border-box` / `content-box`。
- 计算内容宽度、盒子总宽度和外部占位。
- 用图形展示 margin、border、padding 和 content 的关系。

### 第 5 章：Flexbox 与 Grid

- 切换 Grid 与 Flexbox。
- 在 Grid 模式下调整列数。
- 观察一维排列和二维轨道的区别。

### 第 6 章：定位与层叠

- 切换 sticky / absolute 等定位方式。
- 调整 z-index。
- 观察页面层、导航层和提示层之间的关系。

### 第 7 章：综合布局检查

- 选择内容层级、间距系统、颜色数量和页面骨架等问题。
- 观察对应的最小修复建议。
- 将前六章的知识组合起来进行综合检查。

## 状态和数据保存

项目使用浏览器 `localStorage` 保存本地学习状态：

- `layout-lab-language`：当前语言。
- `layout-lab-last-chapter`：最近访问章节。
- `layout-lab-last-section`：最近访问小节。
- `layout-lab-state-*`：各章节小节实验参数。

Global Workspace 主要保存页面宽度、侧栏比例、页面间距、内边距、Section Gap、Demo 宽度、Header 高度、Card Grid Span、元素 inline CSS、元素文本、同级 DOM 顺序和对比状态。刷新页面后已保存的修改会恢复；点击重置后恢复本章初始状态。

## 视觉设计系统

- 浅灰白环境背景。
- 白色或柔白色内容前景。
- 深墨蓝 / 深灰黑正文。
- 品牌紫只用于当前状态、操作、选中和关键高亮。
- 极淡紫灰作为辅助背景。
- 大模块约 18–28px 圆角，小模块约 10–16px 圆角。
- 使用柔和阴影和浅边框建立悬浮层次。
- 用留白、细分隔线、背景色和排版建立结构，减少“边框套边框”。
- 首页、章节总览、小节阅读器和 Global Workspace 共享圆润、轻悬浮、editorial、layered 的视觉语言。

Global Workspace 额外遵循“网页优先”的层级：

1. App Chrome：极简工具栏。
2. Canvas Background：浅灰网格环境。
3. Real Website：白色真实课程页面。
4. Editor Overlay：仅在交互时出现的选中框、控制点和辅助线。

## 技术实现

- HTML5：页面结构、语义元素、课程内容和真实 DOM。
- CSS3：Grid、Flexbox、正常文档流、盒模型、定位、层叠、动画和响应式断点。
- 原生 JavaScript：页面渲染、事件绑定、状态管理、LocalStorage 和交互逻辑。
- D3.js 7：DOM 层级、树结构、色彩、盒模型等可视化。
- `getBoundingClientRect()`：计算真实元素在 Canvas 中的 Overlay 位置。
- `ResizeObserver`：监听元素尺寸变化并刷新选中框和浮层。
- `requestAnimationFrame`：合并拖动过程中的几何刷新。
- Pointer Events：处理点击、宽度调整、高度调整和同级排序。
- `structuredClone`：保存拖动事务前后的可恢复状态。
- LocalStorage：保存语言、章节、小节和 Workspace 本地状态。
- D3.js 通过 CDN 加载，首次打开动态演示时需要网络连接。

## 本地运行

项目是无构建依赖的静态前端，可以使用 Python 静态服务器运行。

在项目根目录打开 PowerShell：

```powershell
python -m http.server 8000
```

访问：

```text
http://localhost:8000/
```

停止服务器：`Ctrl + C`。

常用入口：

```text
首页：          http://localhost:8000/index.html
第 1 章总览：   http://localhost:8000/chapters/chapter-01.html
第 1 小节：     http://localhost:8000/chapters/chapter-01-section-01.html
Global：        http://localhost:8000/workshop/chapter-01.html
```

从小节进入 Global Workspace 时，也可以使用 `from` 查询参数保留来源小节，例如：

```text
http://localhost:8000/workshop/chapter-01.html?from=1
```

也可以直接双击 `index.html`。如果浏览器对本地文件跨目录资源或 CDN 加载有限制，建议使用静态服务器。

## Global Workspace 操作流程

1. 打开 `workshop/chapter-01.html`。
2. 默认先观察真实课程页面，不打开编辑器 Overlay。
3. 点击标题、正文、侧栏或内容区，确认出现浮动属性面板。
4. 点击 CSS，查看当前元素真实样式和尺寸。
5. 修改宽度、padding 或间距，观察页面自然 reflow。
6. 点击网格或边界，打开对应辅助 Overlay。
7. 切换到拖动模式，拖动 Section / Card，在合法父容器内改变同级 DOM 顺序。
8. 点击 DOM，查看当前选中元素的祖先路径和真实结构。
9. 点击对比，观察 Original / Current 状态。
10. 点击重置并确认，恢复本章实验初始状态。
11. 点击返回课程，回到当前来源小节课程阅读页。

## 功能边界与设计原则

### 真实网页优先

Global Workspace 的 Canvas 不是图片、截图或绘图区域，而是直接渲染的 HTML / CSS 页面。所有交互都对应真实元素、真实 CSS 和真实布局结果。

### Web Layout 优先

拖动行为受到父容器、Grid、Flex、正常文档流和 DOM 顺序约束。用户可以调整宽度、跨度、间距和顺序，但不能把元素随意拖到任意 x / y 坐标。

### 编辑器与网页分离

结构标签、选中框、边界、网格、尺寸手柄和 DOM 路径都是编辑器 Overlay 或浮动面板信息，不写进真实网页内容层，也不改变网页本身排版。

### 默认状态克制

默认页面首先应该像一张普通课程网站截图。只有在用户点击、拖动或打开工具之后，编辑器能力才逐步显现。

### 观察和修改分开

DOM、CSS、网格和边界主要用于观察；尺寸输入、边缘拖拽和排序操作用于修改。观察工具不偷偷改变页面布局。

## 课程学习目标

完成课程后，学习者应能：

- 从内容关系而不是装饰属性开始分析页面。
- 区分包含、流动、对齐和优先关系。
- 用 DOM 层级解释页面空间骨架。
- 解释 Grid、Flexbox 和正常文档流如何分配空间。
- 理解 width、padding、border、margin 和 box-sizing 对尺寸的影响。
- 使用字号、行长、间距和基线建立阅读节奏。
- 判断颜色和对比度是否改变视觉层级。
- 理解定位参照、sticky、absolute、z-index 和层叠上下文的边界。
- 在真实网页中通过直接操作验证布局假设。
- 将视觉问题翻译成可描述、可修改、可验证的 CSS 和结构问题。
